# 18/04/2026
- Equipment: Insta360 Ace Pro 2 + Tripod
- Location: Mt Karangahake
- Exposure Time: 1 Hour 34 Minutes
- Object: Milky Way
- Time: 7:15 PM

Reflection on this shot:
I was incredibly happy with this amazing shot. The sky there was near bortle 2 so it was very very dark. Luckily it was a clear night as well. For my first shot of the milky way using the insta360, I was very happy and a bit emotional as well as I finally got to capture not only the milky way, but also the nebulae, constellations and even shooting stars! The trees also gives this image a very good foundation. I am overall increibly satisfied with this result, and this will most likely be my best image of the milky way for a long long time!
